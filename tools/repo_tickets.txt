Title: Text DFM lexer -- tokenize text form files
Issue: #4
Status: closed
Labels: enhancement
Body:
Implement a dedicated lexer for the DFM/FMX text form file format. This is
intentionally separate from delphi-lexer because DFM treats `{ hex }` as
binary data (not comments).

## Deliverables

- [ ] `source/Delphi.Forms.Token.pas` -- `TDfmTokenKind` enum and `TDfmToken` record
- [ ] `source/Delphi.Forms.Lexer.pas` -- `TDfmLexer.Tokenize()` producing `TDfmTokenList`
- [ ] `test/Test.Delphi.Forms.Lexer.pas` -- comprehensive lexer tests

## Token kinds

`dtkIdentifier`, `dtkInteger`, `dtkFloat`, `dtkString`, `dtkCharLiteral`,
`dtkEquals`, `dtkColon`, `dtkDot`, `dtkComma`, `dtkPlus`, `dtkMinus`,
`dtkLBracket`, `dtkRBracket`, `dtkLParen`, `dtkRParen`, `dtkLAngle`,
`dtkRAngle`, `dtkBinaryData`, `dtkWhitespace`, `dtkEOL`, `dtkEOF`

## Design invariants

- Round-trip: concatenating all Token.Text reproduces original source exactly
- Every character appears in exactly one token (no gaps, no overlaps)
- `{ hex }` produces `dtkBinaryData`, NOT a comment token
- Final token is always `dtkEOF`

## Acceptance criteria

- [ ] 0 warnings, 0 errors
- [ ] All lexer tests pass with zero memory leaks
- [ ] Round-trip verified on representative DFM snippets

Title: Text DFM parser -- recursive descent tokens to AST
Issue: #5
Status: closed
Labels: enhancement
Body:
Implement a recursive-descent parser that converts TDfmTokenList into a
TFormFile AST. Handles all DFM constructs: object/inherited/inline blocks,
properties with dotted names, and all value types (integers, floats, strings,
booleans, identifiers, sets, binary data, parenthesized lists, collections).

## Deliverables

- [ ] `source/Delphi.Forms.Parser.pas` -- `TDfmParser.Parse(Source): TFormFile`
- [ ] `test/Test.Delphi.Forms.Parser.pas` -- parser tests covering all value
  types, nested objects, inherited/inline forms, dotted property names,
  string concatenation with `+` and `#` char literals

## Grammar

```
FormFile       = Object EOF
Object         = ObjectKw Ident ':' Ident EOL PropertyOrChild* 'end'
ObjectKw       = 'object' | 'inherited' | 'inline'
Property       = DottedName '=' Value
Value          = NumericValue | StringValue | BoolValue | IdentValue
               | SetValue | BinaryValue | ListValue | CollectionValue
```

## Acceptance criteria

- [ ] 0 warnings, 0 errors
- [ ] All parser tests pass with zero memory leaks
- [ ] Parses representative DFM snippets into correct AST structure

Title: Text DFM writer -- AST to text with round-trip fidelity
Issue: #6
Status: closed
Labels: enhancement
Body:
Implement a text writer that serializes TFormFile back to DFM text format.
This is a core component -- round-trip fidelity (parse then write == original)
is a design invariant verified on every parse.

## Deliverables

- [ ] `source/Delphi.Forms.TextWriter.pas` -- `TDfmTextWriter.Write(FormFile): string`
- [ ] `test/Test.Delphi.Forms.TextWriter.pas` -- writer tests including
  round-trip verification (parse -> write -> compare == original)

## Design

- When RawText is available on values (text-parsed ASTs), use it for exact
  round-trip reproduction
- When RawText is empty (binary-parsed ASTs), produce canonical formatting:
  2-space indent per nesting level, hex data wrapped at 64 chars per line
- Canonical output must be re-parseable (write -> parse -> write is stable)

## Acceptance criteria

- [ ] 0 warnings, 0 errors
- [ ] All writer tests pass with zero memory leaks
- [ ] Round-trip verified: parse(source) -> write -> equals source
